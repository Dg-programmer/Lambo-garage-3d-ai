# Lambo-garage-3d-ai
made a three js garage view of lamborini huracan model

![Huracán STO rendered in the showroom](assets/sto-garage.webp)

## Run locally

Run this command from the repository root.

```sh
python -m http.server 4185 --bind 127.0.0.1
```

Open the [local showroom](http://127.0.0.1:4185/). Drag to orbit the car or select an assembly to open its exploded view. Optional hand controls require browser camera permission.
